# Ayurvedic Home Diet & Yoga Assistant 🌿🧘‍♂️

## Description
AI-based assistant that provides personalized Ayurvedic diet,
yoga recommendations, and home remedies based on user assessment.

## Tech Stack
- Frontend: React
- Backend: Node.js, Express
- ML: Python, Scikit-learn
- Database:  MySQL
